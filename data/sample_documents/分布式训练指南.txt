# PyTorch 分布式训练配置指南

## 1. 文档目的

本指南提供在算力集群上进行 PyTorch 分布式训练的完整配置说明，包括环境设置、通信配置、并行策略和性能优化建议。

## 2. 环境配置

### 2.1 基础环境

| 组件 | 版本要求 | 说明 |
|------|----------|------|
| Python | 3.9+ | 推荐 3.10 |
| PyTorch | 2.1+ | 推荐 2.2 (CUDA 12.x) |
| CUDA | 12.1+ | 支持 TransformerEngine |
| NCCL | 2.19+ | 性能优化关键 |
| cuDNN | 8.9+ | 加速卷积运算 |

### 2.2 通信后端选择

| 后端 | 适用场景 | 带宽 | 延迟 |
|------|----------|------|------|
| NCCL | GPU-GPU 通信 (推荐) | 900 GB/s | < 1 μs |
| GLOO | CPU/GPU 混合 | - | 较高 |
| MPI | 多机扩展 | - | 低 |

**配置示例：**
```bash
# 设置 NCCL 通信后端
export NCCL_DEBUG=INFO
export NCCL_IB_TIMEOUT=22
export NCCL_IB_RETRY_CNT=7

    --rdzv_id=12345 \
```

## 3. 张量并行 (Tensor Parallelism)

### 3.1 原理说明

张量并行将单个层的参数矩阵按列或行分割到多个 GPU，实现计算和显存的分布式处理。

### 3.2 配置方法

```python
import torch
from torch.distributed.tensor.parallel import (
    RowParallelLinear,
    ColParallelLinear,
    parallelize_module,
)

# Megatron-LM 风格配置
TP_SIZE = 8  # 张量并行度
PP_SIZE = 4  # 流水线并行度
DP_SIZE = 16 # 数据并行度

# 确保 TP_SIZE × PP_SIZE × DP_SIZE = 总 GPU 数
```

### 3.3 张量并行配置参数

| 参数 | 推荐值 | 说明 |
|------|--------|------|
| tensor_parallel_size | 8 | 建议 2/4/8 |
| memory_fraction | 0.9 | GPU 显存使用比例 |
| gather_output | True | 是否汇聚输出 |

## 4. 流水线并行 (Pipeline Parallelism)

### 4.1 流水线策略

| 策略 | 说明 | 优点 | 缺点 |
|------|------|------|------|
| 1F1B | 1 Forward 1 Backward | 内存占用低 | 流水线不饱满 |
| Interleaved | 交错执行 | 效率更高 | 实现复杂 |
| GPipe | 同步流水线 | 正确性保证 | 气泡多 |

### 4.2 流水线配置

```python
from torch.distributed.pipeline.sync import Pipe

# 流水线配置
BATCH_SIZE = 32
MICRO_BATCH_SIZE = 2
NUM_MICRO_BATCHES = BATCH_SIZE // MICRO_BATCH_SIZE

# 流水线并行封装
model = Pipe(model, chunks=MICRO_BATCH_SIZE)
```

### 4.3 流水线参数调优

| 参数 | 小规模 | 中规模 | 大规模 |
|------|--------|--------|--------|
| PP_SIZE | 2 | 4 | 8 |
| MICRO_BATCH_SIZE | 4-8 | 2-4 | 1-2 |
| NUM_STAGES | 12 | 24 | 48 |

## 6. 梯度累积

### 6.1 配置方法

```python
# 梯度累积步数配置
GRADIENT_ACCUMULATION_STEPS = 4
EFFECTIVE_BATCH_SIZE = BATCH_SIZE * GRADIENT_ACCUMULATION_STEPS * DP_SIZE

# PyTorch 原生实现
for step, batch in enumerate(dataloader):
    outputs = model(batch)
    loss = criterion(outputs, target)
    loss = loss / GRADIENT_ACCUMULATION_STEPS
    loss.backward()
    
    if (step + 1) % GRADIENT_ACCUMULATION_STEPS == 0:
        optimizer.step()
        optimizer.zero_grad()
```

### 6.2 推荐配置

| 总 batch size | 单卡 batch | 累积步数 | 数据并行度 |
|---------------|------------|----------|------------|
| 4096 | 8 | 4 | 128 |
| 8192 | 8 | 4 | 256 |
| 16384 | 8 | 8 | 256 |
| 32768 | 8 | 16 | 256 |

## 7. 混合精度训练

### 7.1 BF16 vs FP16 对比

| 特性 | BF16 | FP16 |
|------|------|------|
| 动态范围 | 8 bit 指数 | 5 bit 指数 |
| 精度 | 更高 | 较低 |
| 溢出风险 | 较低 | 较高 |
| 性能 | 略低 | 略高 |
| 推荐场景 | LLM 训练 | CV/NLP 分类 |

### 7.2 混合精度配置

```python
from torch.cuda.amp import autocast, GradScaler

# 推荐使用 BF16
scaler = GradScaler('cuda')
AUTOCAST_DTYPE = torch.bfloat16  # 推荐

# 训练循环
for batch in dataloader:
    with autocast(dtype=AUTOCAST_DTYPE):
        outputs = model(batch)
        loss = criterion(outputs, target)
    
    scaler.scale(loss).backward()
    scaler.unscale_(optimizer)
    torch.nn.utils.clip_grad_norm_(model.parameters(), 1.0)
    scaler.step(optimizer)
    scaler.update()
```
