# 算力集群存储系统配置说明

## 1. 存储系统概述

本文档描述算力集群的存储架构、目录规划、配额管理和访问策略。

## 2. 存储架构

### 2.1 并行文件系统

集群采用 **Lustre + GPFS 混合架构**：

| 文件系统 | 规模 | 协议 | 主要用途 |
|----------|------|------|----------|
| Lustre | 20 PB | LNET/IB | 高速训练数据 |
| GPFS | 10 PB | NFS/SMB | 企业级存储 |
| BeeGFS | 5 PB | IB/ETH | Checkpoint 存储 |

### 2.2 存储集群规格

**Lustre 存储集群：**
- 集群带宽：800 GB/s (聚合)
- 元数据服务器：4 台 (MDS)
- 对象存储服务器：64 台 (OSS)
- 单 OSS 带宽：12.5 GB/s
- 单文件系统容量：20 PB

**GPFS 存储集群：**
- 集群带宽：200 GB/s
- 存储节点：32 台
- 单节点带宽：6.25 GB/s
- 总容量：10 PB

## 3. 存储目录规划

### 3.1 目录结构

| 挂载点 | 文件系统 | 容量 | 用途 | 备份策略 |
|--------|----------|------|------|----------|
| /data | Lustre | 15 PB | 训练数据集 | 快照每日 |
| /checkpoint | BeeGFS | 3 PB | 模型检查点 | 实时复制 |
| /scratch | Lustre | 3 PB | 临时计算 | 无备份 |
| /home | GPFS | 500 TB | 用户主目录 | 快照每周 |
| /project | GPFS | 2 PB | 项目共享数据 | 快照每日 |

### 3.2 目录权限

| 目录 | 读权限 | 写权限 | 说明 |
|------|--------|--------|------|
| /data | 所有用户 | 指定组 | 公共数据集 |
| /checkpoint | 所有者 | 所有者 | 训练检查点 |
| /scratch | 所有者 | 所有者 | 临时文件 (7天后清理) |
| /home | 所有者和组 | 所有者 | 主目录 |
| /project | 项目成员 | 项目成员 | 项目共享 |

## 4. 存储配额管理

### 4.1 配额类型

| 配额类型 | 单位 | 默认软限制 | 默认硬限制 |
|----------|------|------------|------------|
| 存储空间 | TB | 10 TB | 12 TB |
| 文件数量 | 万个 | 100 | 120 |
| inode 数量 | 万个 | 50 | 60 |

### 4.2 用户配额配置

```bash
# 查看配额
lfs quota -u username /data
lfs quota -g project_group /data

# 配额示例输出
Disk quotas for user alice (uid 1001):
     Filesystem   kbytes   quota   limit   inodes   quota   limit
            /data 5242880000 10485760000 12582912000   50000   100000   120000
```

### 4.3 配额超限处理

| 条件 | 行为 |
|------|------|
| 超过软限制 | 发送警告邮件，14天内有效 |
| 超过硬限制 | 禁止写入，需清理或申请扩容 |
| 超过宽限期 | 自动删除最早文件 |

## 5. 多租户存储隔离

### 5.1 项目存储隔离

每个项目拥有独立的存储池：

```yaml
project_storage:
  project_alpha:
    primary_fs: Lustre
    quota: 500TB
    dedicated_oss: 8
    bandwidth_share: 25%
    
  project_beta:
    primary_fs: GPFS
    quota: 200TB
    bandwidth_share: 15%
    
  project_gamma:
    primary_fs: BeeGFS
    quota: 100TB
    bandwidth_share: 10%
```

### 5.2 QoS 配置

| 优先级 | 带宽保证 | 带宽上限 | IOPS 保证 |
|--------|----------|----------|-----------|
| 高 | 50% | 200% | 50000 |
| 中 | 30% | 100% | 25000 |
| 低 | 10% | 50% | 10000 |

### 5.3 存储隔离机制

- **网络隔离**：项目间使用不同 VLAN
- **LUN 隔离**：块存储使用独立 LUN
- **目录隔离**：文件系统使用独立目录 + ACL
- **配额隔离**：独立配额组

## 7. 数据迁移

### 7.1 迁移工具

| 工具 | 适用场景 | 带宽利用率 |
|------|----------|------------|
| lfs_migrate | Lustre 内部迁移 | 70-80% |
| rsync | 跨文件系统 | 60-70% |
| dd | 裸设备复制 | 90-95% |
| HPC MPI-IO | 大文件并行 | 85-90% |

### 7.2 迁移命令示例

```bash
# Lustre 文件迁移
lfs_migrate -l -y -E 100M -c 32 /data/large_file

# 目录批量迁移
lfs_migrate -r -y /checkpoint/old_project/

# 检查迁移状态
lfs_migrate --status /data/migrating_file
```

## 8. 备份与恢复

### 8.1 备份策略

| 数据类型 | 备份频率 | 保留周期 | 恢复 RTO |
|----------|----------|----------|----------|
| 训练数据集 | 每日快照 | 30 天 | 1 小时 |
| 检查点 | 实时复制 | 7 天 | 10 分钟 |
| 用户代码 | 每周快照 | 90 天 | 4 小时 |
| 配置文档 | 版本控制 | 永久 | 即时 |

### 8.2 快照操作

```bash
# 创建快照
lfs setstripe -S 4M /data/.snapshot/daily_20260401

# 列出快照
ls -la /data/.snapshot/

# 从快照恢复
cp -a /data/.snapshot/daily_20260401/file /data/file
```

## 9. 常见问题处理

### 9.1 性能问题排查

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 写入速度慢 | 未条带化 | lfs setstripe -c 32 |
| 元数据压力大 | 小文件过多 | 打包或合并 |
| OST 不均衡 | 条带不均 | lfs rebalance |
| 客户端缓存失效 | 刷新问题 | sync; lfs flush |

### 9.2 条带化配置

```bash
# 查看当前条带化
lfs getstripe /data/dataset

# 设置目录默认条带
lfs setstripe -c 32 -S 4M /data/new_project

# 条带化参数说明
# -c: 条带数量 (1-200)
# -S: 条带大小 (1M-16M, 推荐 4M)
# -i: 起始 OST 索引
```
