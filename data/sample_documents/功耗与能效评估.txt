# 功耗与能效评估指南

## 1. 文档说明

本指南提供算力集群能效优化的策略、功耗管理配置和评估指标，用于提升集群整体能效比。

## 2. 能效指标体系

### 2.1 核心指标

| 指标 | 定义 | 当前值 | 目标值 |
|------|------|--------|--------|
| PUE | 电能利用效率 | 1.35 | 1.30 |
| DPPE | 数据中心性能效率 | 0.72 | 0.78 |
| CUE | 碳利用效率 | 0.5 kg/kWh | 0.4 kg/kWh |
| WUE | 水利用效率 | 0.5 L/kWh | 0.4 L/kWh |

**指标计算公式：**
```
PUE = Total Facility Power / IT Equipment Power
CUE = Total CO2 Emissions / IT Equipment Energy
WUE = Total Water Usage / IT Equipment Energy
```

### 2.2 GPU 能效指标

| 指标 | 定义 | 优秀 | 良好 | 及格 |
|------|------|------|------|------|
| GPU 能效比 | TFLOPS/W | > 1.2 | 0.8-1.2 | 0.5-0.8 |
| GPU 利用率 | 实际/峰值算力 | > 80% | 60-80% | 40-60% |
| GPU 空闲功耗 | 空闲时功耗/TDP | < 30% | 30-50% | > 50% |

### 2.3 Green500 排名指标

Green500 使用 **HPL (High Performance Linpack)** 作为基准测试，衡量每瓦浮点性能：

```
Green500 Score = HPL Performance (PFLOPS) / Power Consumption (kW)
```

**典型 Green500 排名水平：**

| 排名 | 能效比 (GFLOPS/W) | 典型配置 |
|------|-------------------|----------|
| Top 10 | > 60 | 全液冷 + 先进封装 |
| Top 100 | 50-60 | 液冷 + 高密度 |
| Top 500 | 40-50 | 混合冷却 |
| 一般超算 | 20-40 | 风冷为主 |

## 3. GPU 动态功耗调节

### 3.1 功耗状态 (P-States)

GPU 功耗管理支持多个性能状态：

| P-State | 频率 (MHz) | 电压 (mV) | 功耗占比 | 适用场景 |
|---------|------------|-----------|----------|----------|
| P0 | 1090 | 850 | 100% | 高负载训练 |
| P1 | 900 | 800 | 80% | 通用计算 |
| P2 | 700 | 750 | 60% | 中等负载 |
| P3 | 500 | 700 | 40% | 推理服务 |
| P4 | 300 | 650 | 25% | 低负载 |
| P5 | 135 | 600 | 15% | 空闲状态 |
| P6 | 135 | 600 | 10% | 深度睡眠 |
| P7 | 135 | 600 | 5% | 最小功耗 |

### 3.2 核心空闲状态 (C-States)

| C-State | 说明 | 唤醒延迟 | 功耗节省 |
|---------|------|----------|----------|
| C0 | 工作状态 | 0 | 0% |
| C1 | 空闲等待 | 10 μs | 10-20% |
| C3 | 深度空闲 | 100 μs | 30-40% |
| C6 | 深度睡眠 | 1 ms | 60-70% |
| C7 | 最深睡眠 | 10 ms | 80-90% |

### 3.3 功耗调节配置

```bash
# 查看当前功耗状态
nvidia-smi -q -d PERFORMANCE

# 设置性能模式
nvidia-smi -pm 1                    # 启用持久模式
nvidia-smi -pl 350                  # 设置功率上限 (Watts)
nvidia-smi -lgc 300,1090            # 设置时钟频率范围

# 启用自动功耗管理
nvidia-smi -autoboost=1             # 启用自动加速
nvidia-smi -ac 877,1530            # 设置应用时钟 (MHz)

# 查看功耗历史
nvidia-smi -q -d POWER -l 1         # 每秒采样
```

### 3.4 动态频率调节策略

| 负载场景 | 策略 | 配置 |
|----------|------|------|
| 满载训练 | 最大性能 | P0 + 最大频率 |
| 中等训练 | 平衡 | P1 + 动态调节 |
| 推理服务 | 节能 | P3 + 动态调节 |
| 空闲待机 | 最小功耗 | P7 + C6 |

```python
# 智能功耗管理示例
class GPUPowerManager:
    def __init__(self, target_util=75):
        self.target_util = target_util
        
    def adjust_power_state(self, current_util):
        if current_util < 30:
            self.set_state("P3")  # 降频节能
        elif current_util < 60:
            self.set_state("P2")
        elif current_util < 85:
            self.set_state("P1")
        else:
            self.set_state("P0")  # 最大性能
```

## 5. 能效优化策略

### 5.1 优化措施矩阵

| 措施 | PUE 改善 | 实施成本 | 实施周期 | 优先级 |
|------|----------|----------|----------|--------|
| 冷通道封闭 | -0.05 | 低 | 1周 | 高 |
| 温度调高 2°C | -0.03 | 无 | 即时 | 高 |
| 自然冷却 | -0.10 | 中 | 2周 | 中 |
| 液冷改造 | -0.15 | 高 | 3月 | 中 |
| 动态制冷调节 | -0.05 | 中 | 1月 | 高 |
| GPU 功率封顶 | -0.02 | 无 | 即时 | 中 |

### 5.2 温度优化建议

根据 ASHRAE A1 标准，推荐运行区间：

| 参数 | ASHRAE 推荐 | 集群当前 | 优化空间 |
|------|-------------|----------|----------|
| 进风温度 | 18-27°C | 24°C | 可提至 26°C |
| 相对湿度 | 40-60% | 50% | 最佳区间 |
| 露点温度 | 5.5-15°C | 12°C | 最佳区间 |

### 5.3 GPU 利用率优化

**目标：平均 GPU 利用率 > 75%**

| 利用率区间 | 问题诊断 | 解决方案 |
|------------|----------|----------|
| < 30% | 数据加载瓶颈 | 优化 DataLoader |
| 30-50% | CPU 预处理慢 | 增加 workers |
| 50-70% | 通信开销大 | 优化 batch size |
| 70-85% | 正常 | 保持 |
| > 85% | 显存可能不足 | 启用梯度累积 |

### 5.4 负载均衡策略

```python
# 能效感知的负载均衡
def schedule_job_based_on_efficiency(job_requirements):
    """
    选择能效比最高的节点分配作业
    """
    candidates = []
    
    for node in available_nodes:
        # 计算节点能效评分
        gpu_power = node.gpu_count * node.gpu_tdp
        cpu_power = estimate_cpu_power(node)
        total_power = gpu_power + cpu_power
        
        efficiency_score = (
            job_requirements.flops / total_power
        ) * node.current_efficiency_factor
        
        candidates.append((node, efficiency_score))
    
    # 选择能效最高的节点
    return max(candidates, key=lambda x: x[1])
```
